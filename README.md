# Background Check Automation System

## 🚀 Overview

Automation system for generating background check reports using Python, web data extraction, and document generation.

This solution eliminates manual bottlenecks in report creation by automating data retrieval, validation, and PDF generation.

---

## 📊 Business Impact

* Processes **70–120 reports per day**
* Reduced manual workload from **3 employees to 1**
* Eliminated reporting backlog
* Reduced report generation time to **~30 seconds per report**

---

## ⚙️ Key Features

* Automated data extraction from Google Sheets
* Integration with external data sources (government & police records)
* Automated screenshot capture of validation results
* Dynamic PDF report generation (standardized one-page format)
* QR code generation for validation and verification
* Automatic file storage in Google Drive

---

## 🧩 Process Flow

1. Read input data from Google Sheets
2. Query external systems for background validation
3. Capture evidence (screenshots / records)
4. Generate standardized PDF report
5. Attach validation data and QR code
6. Store final report in cloud storage

---

## 🛠️ Tech Stack

* Python
* Selenium (web automation)
* Google Sheets API
* PDF generation libraries
* QR code generation
